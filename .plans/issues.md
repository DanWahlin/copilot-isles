# Issues log

Problems, gaps, and deferred decisions found while building. Newest first within each section.
Status: **open** · **fixed** · **deferred** (with the phase it moves to) · **wontfix** (with a reason).

| # | Area | Issue | Severity | Status | Notes |
|---|---|---|---|---|---|
| 1 | Sky | Phase 0a sky is three's TSL `SkyMesh` (Preetham + 2D cloud layer), not Hillaire LUTs; the env map refreshes whole (not progressive per-face). | Medium | deferred (0b/Phase 1) | Env refresh uses one stable PMREM target (no recompiles). Budget the refresh cost in T17. |
| 2 | Sky | SkyMesh clouds animate on three's render timer, so they don't pause with the game or damp under reduced motion. | Low | open | Fork SkyMesh's cloud drift onto `world.time` × (1 − reducedMotion). |

Verify it doesn't oscillate in T17. |
